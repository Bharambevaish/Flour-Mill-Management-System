# Landing hero media

Put the hero clip here and the landing page uses it instead of the drawn chakki
(no code change needed):

- `hero.mp4` — square (1:1), 6–10 s seamless loop, no audio, H.264, ideally < 3 MB
- `hero.webm` — optional, same clip as VP9 (smaller)
- `hero.jpg` — poster frame / still shown before playback and to visitors who
  prefer reduced motion
- or just `hero.webp` / `hero.jpg` for a still image

Remove the files to go back to the animated illustration.
